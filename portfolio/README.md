# JR Nibir Hasan — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Preview / deployment
This website is located in the `portfolio/` folder. Once deployed on Vercel with the root directory set to `portfolio`, the `index.html` file is served as the homepage.

## Customize
- Update the bio, project cards, and education text in `index.html`.
- Update the contact email and social links to your preferred public profiles.
- Replace the initials card with a profile photo if desired.

No build step or package installation is required.
